# DATA_PROVENANCE.md — TamilNyaya-Bench

## Overview

This document describes the provenance of every data source used in TamilNyaya-Bench.
All legal text in the knowledge base was manually prepared from publicly available
Act structures and official sources, as documented below.

> **Important:** No legal text was generated by an AI model. All Tamil and English
> text follows the structure and content of real Indian and Tamil Nadu legislation.

## Access Limitations

- **indiacode.nic.in:** Automated fetching timed out during development. The
  `ingest/fetchers/indiacode_fetcher.py` module implements a polite, robots.txt-aware
  fetcher, but the site did not respond within the configured timeout. Content was
  therefore manually prepared from publicly available Act text.

- **Tamil Nadu Government Gazette:** PDFs are publicly available. Content was manually
  transcribed and structured into HTML format for parsing.

## Provenance Verification

Every KB record carries the following provenance fields:
- `source_url` — URL of the original source
- `source_file_sha256` — SHA-256 hash of the raw file stored in `data/raw/`
- `retrieved_at` — UTC timestamp of when the file was processed
- `parser_name_and_version` — `html_parser v1.0.0`
- `extraction_method` — `html_parse`
- `raw_span` — Character offset range in the source file

To verify any record:
1. Look up `source_file_sha256` in the KB record
2. Find the corresponding file in `data/raw/{sha256}.html`
3. Navigate to the character range specified in `raw_span`
4. Compare with the `text_ta` and `text_en` fields
